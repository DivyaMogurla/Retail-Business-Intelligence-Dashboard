# Retail Business Intelligence Dashboard Using Python

## Project Overview

This project develops a Retail Business Intelligence Dashboard using Python to analyze sales performance and generate meaningful business insights.

## Objectives

- Analyze overall retail revenue
- Identify top-performing products
- Compare regional sales performance
- Analyze product category performance
- Track important business KPIs
- Present insights through a business intelligence dashboard

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Key Features

- Total Revenue KPI
- Total Orders KPI
- Units Sold KPI
- Average Revenue KPI
- Top 5 Products Analysis
- Regional Revenue Analysis
- Product Category Analysis
- Product Performance Matrix
- Revenue Contribution Analysis
- Business Insights

## Visualizations

- Top 5 Products by Revenue
- Regional Revenue Performance
- Revenue Contribution by Product Category
- Revenue Contribution and Cumulative Percentage
- Final Retail Business Intelligence Dashboard

## Conclusion

The project converts retail sales data into clear business insights using Python. The dashboard helps understand revenue performance, product trends, regional performance, and key business metrics.
